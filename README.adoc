DATEX II VMS Table Publication – Tabulka proměnných dopravních značek. Statický popis proměnných dopravních značek: umístění, typ, konfigurace.

Repozitář formátu Národního dopravního informačního centra (NDIC) – specifikace datového profilu
DATEX II 3.7 a jeho dokumentace. Aktuální verze formátu: *1.3*.

toc::[]

== Obsah

[horizontal]
`FORMAT.yaml`:: metadata formátu: identifikátor `x-format:<formát>-vX.Y`, verze MAJOR.MINOR
`schema/`:: závazné XML schéma (XSD)
`sel/`:: výběr profilu z modelu DATEX II (webtool DATEX II)
`samples/`:: vzorky dat, validní vůči schématu
`res/`:: doplňkové materiály pro odběratele (např. tabulka piktogramů)
`CHANGELOG.adoc`:: změny formátu
`docs/`:: zdrojové texty dokumentace (AsciiDoc); každá jazyková varianta (`docs/cs`, `docs/en`) má vlastní `DOC.yaml` s revizí

== Vydání

Vydání jsou v sekci *Releases* tohoto repozitáře:

[cols="1,3"]
|===
|tag |obsah

|`vX.Y` |balíček specifikace `cz-ndic_d2-vms-table-vX.Y.zip` (FORMAT.yaml, schéma, výběr profilu, vzorky, doplňkové materiály, CHANGELOG)
|`docs-<jazyk>-vX.Y.N` |dokumentace formátu v jazyce `cs`/`en` (PDF, HTML); `X.Y` = verze formátu, `N` = revize textu dané jazykové varianty
|===
